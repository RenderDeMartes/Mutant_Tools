# Example geometry

Reproducible meshes generated by `npm run examples` (`scripts/generate-examples.ts`). All shapes are
synthetic and deterministic, so tests and benchmarks can rely on them.

| File | Role | Contents |
| --- | --- | --- |
| `base_quadsphere.obj` | Base | 9,602-vertex all-quad sphere with UVs, a group and smoothing group (checks attribute round-trip) |
| `base_quadsphere_lowpoly.obj` | Base | 866-vertex quad sphere for quick experiments |
| `reference_head_cm.obj` | Reference | 40,962-vertex triangulated stylised head in centimetres, rotated 10.3° about Y and offset — needs alignment first |
| `reference_head_partial_scan.ply` | Reference | Same head (unit scale) with the back of the skull cut away (open boundary), binary PLY |
| `reference_head.stl` | Reference | Same head as binary STL (STL is accepted as Reference only) |

Suggested walkthrough: load `base_quadsphere.obj` + `reference_head_cm.obj` → Auto (bounds) → ICP refine →
optionally place landmarks on the nose tip and ears → Run wrap → Commit → Export OBJ, then diff the exported
file against the original: only `v` lines change.
